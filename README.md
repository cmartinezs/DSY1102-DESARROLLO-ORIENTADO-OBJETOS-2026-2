# DSY1102 · Desarrollo Orientado a Objetos · 2026-2

Repositorio de apoyo para la asignatura **DSY1102 Desarrollo Orientado a Objetos**.

Este repositorio reúne contenido de clases, ejemplos, ejercicios, laboratorios, guías y recursos complementarios utilizados durante el semestre 2026-2.

La asignatura desarrolla progresivamente soluciones de software con **Java y Programación Orientada a Objetos**, continúa con **interfaces gráficas JavaFX + MVC + persistencia en JSON**, y finaliza integrando **bases de datos relacionales mediante JDBC**.

- [`docs/`](docs/) — conocimientos y guías transversales.

- [**Material público del curso**](https://drive.google.com/drive/folders/1FmQqQQ6nslfG1OZ8FFhkqgxpnEOkpHZk) — biblioteca de archivos originales organizada semana a semana.

## Resultados de aprendizaje

El curso se organiza en tres grandes etapas:

1. **Fundamentos de Programación Orientada a Objetos** — paradigma OO, tipos, operadores, estructuras de control, métodos, clases, encapsulamiento, herencia, clases abstractas, interfaces, polimorfismo, excepciones y colecciones.
2. **Interfaces gráficas con persistencia en archivo** — Maven, JavaFX, Scene Builder, FXML, componentes UI, eventos, MVC, TableView, navegación, validaciones y persistencia JSON mediante capas Repository/DAO.
3. **Integración con base de datos relacional** — conectividad JDBC, configuración de conexión, CRUD con sentencias parametrizadas, refactorización DAO e integración de la interfaz con la persistencia.

## Cómo se organiza el material

Cada semana mantiene dos fuentes complementarias:

### Contenido consolidado

Se publica en este repositorio dentro de `semanas/semana-XX/`.

El contenido consolidado incorpora:

- los contenidos definidos para la semana;
- explicaciones y ejemplos desarrollados durante las clases;
- ejercicios y laboratorios;
- contexto técnico adicional;
- aclaraciones cuando el material institucional presenta ambigüedades, inconsistencias u omisiones;
- evidencias o proyectos cuando corresponda.

El directorio [`semanas/`](semanas/) mantiene un **README general** que funciona como índice del semestre. Cada carpeta semanal mantiene además su propio `README.md` como punto de entrada.

### Material original

Los archivos originales utilizados durante cada semana se mantienen en la [biblioteca pública de Google Drive](https://drive.google.com/drive/folders/1FmQqQQ6nslfG1OZ8FFhkqgxpnEOkpHZk), organizados en carpetas semanales de solo lectura.
