## Cómo se organiza la práctica

Cada tipo de actividad tiene una función distinta:

- [`practica/`](practica/) — **Práctica de clase**: ejercicios cortos y focalizados.
- [`labs/`](labs/) — **Laboratorios**: actividades guiadas e integradoras con varias etapas.
- [`examples/`](examples/) — **Ejemplos**: código demostrativo reutilizable, separado por semana.
- [`proyecto-formativo/`](proyecto-formativo/) — **Proyecto formativo PetCare**: software longitudinal que evoluciona durante el semestre.
- **Desafío semanal** — problemas menos guiados, usando únicamente materia ya liberada.
- **Grandes desafíos** — entrenamiento acumulativo por etapa del curso.

Los enunciados prácticos completos se publican preferentemente en la web; los Markdown actúan como índices, referencias, guías técnicas o continuidad histórica cuando corresponde.

## Resultados de aprendizaje

El curso se organiza en tres grandes etapas:

1. **Fundamentos Java y Programación Orientada a Objetos** — tipos, operadores, estructuras de control, métodos, clases, encapsulamiento, herencia, abstracción, interfaces, polimorfismo, excepciones y colecciones.
2. **Interfaces gráficas con persistencia en archivo** — Maven, JavaFX, Scene Builder, FXML, eventos, MVC, navegación, validación y persistencia JSON.
3. **Integración con base de datos relacional** — JDBC, CRUD, sentencias parametrizadas, DAO e integración con la interfaz.
