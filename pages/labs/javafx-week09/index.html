Semana 9 · Práctica del sábado

Primera interfaz JavaFX funcional

Proyecto Maven → FXML → Controller → evento → objeto Java. Cada etapa tiene un checkpoint y un commit sugerido.

Preparación autónoma

0 · Configuración

Verifica JDK 21, Maven y Scene Builder. Ejecuta el demo de referencia, anota fallos de instalación y revisa las PPT de JavaFX y FXML.

Ver materias →
Paso 1 · 15 min orientativos

Ventana y Maven

Ejecuta mvn clean javafx:run. Identifica Application, start(Stage), Stage y Scene. Cambia el título y ejecuta de nuevo.

Checkpoint: ventana visible y comando reproducible.

Paso 2 · práctica guiada

Vista FXML

Crea un VBox con Label, TextField y Button usando Scene Builder. Guarda FXML en resources y define fx:controller y fx:id.

Checkpoint: controles cargados desde el archivo FXML.

Controller y evento

Usa @FXML y onAction para leer datos, crear un objeto Java y mostrar resultado. Comprueba el caso vacío sin fallar.

Checkpoint: evento funcional, prueba válida e inválida.
