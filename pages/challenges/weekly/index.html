Máquina de café orientada a objetos

Modela una máquina de café con estado propio. Debe comenzar con una cantidad de agua y café definida mediante constructor.

Reglas mínimas

  • el agua y el café no pueden quedar negativos;
  • prepararCafe() sólo funciona si existen recursos suficientes;
  • una recarga debe recibir valores mayores que cero;
  • el estado interno no se modifica directamente desde main;
  • debe existir una operación para consultar o mostrar el estado actual.

Debes demostrar

  • dos objetos con estados iniciales distintos;
  • preparación válida;
  • preparación rechazada;
  • recarga válida e inválida;
  • estado final independiente de cada objeto.

Restricción: tú decides atributos, constructor, retornos y organización interna. Debes poder justificar por qué cada comportamiento pertenece a la clase.
