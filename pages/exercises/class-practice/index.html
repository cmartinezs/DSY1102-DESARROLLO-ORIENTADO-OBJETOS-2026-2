Práctica de clase

Ejercicios de 5–20 minutos para aplicar inmediatamente uno o pocos conceptos recién trabajados.

¿Buscas una actividad más larga? Revisa Laboratorios o PetCare.

Semana 1 · Fundamentos del lenguaje

1. Conversión de temperatura

Define una temperatura Celsius en código y conviértela a Fahrenheit usando double y operadores aritméticos.

2. Mayor de dos números

Define dos enteros e indica cuál es mayor o si son iguales usando if / else if / else.

3. Clasificación de nota

Con una nota entre 1.0 y 7.0, muestra su clasificación según el rango.

4. Opción con switch

Define una opción entre 1 y 4 y procesa distintas acciones.

5–10

Tabla de multiplicar, cuenta regresiva, acumulador, cajero simplificado, comparación Python→Java y preparación conceptual para POO.

Semana 2 · Fundamentos Java

1. Promedio de evaluaciones

Calcula el promedio de tres notas y determina si aprueba desde 4.0.

2. Control de stock de una cafetería

Parte con 20 sándwiches; durante 5 recreos se venden 3. Usa for, muestra stock y avisa si quedan 5 o menos.

3. Meta de ahorro

Usa while para calcular cuántas semanas se requieren para llegar a una meta.

4. Carga segura de una batería

Usa do while y finaliza por objetivo de carga o temperatura máxima.
