Ejercicios de la clase

Aquí queda la práctica que nace directamente de lo trabajado en cada semana. La web es la fuente canónica; los Markdown del repositorio solo enlazan hacia esta página.

1. Conversión de temperatura

Define una temperatura Celsius en código y conviértela a Fahrenheit usando double y operadores aritméticos.

F = C * 9 / 5 + 32

2. Mayor de dos números

Define dos enteros e indica cuál es mayor o si son iguales usando if / else if / else.

3. Clasificación de nota

Con una nota entre 1.0 y 7.0, muestra: Insuficiente, Suficiente, Bueno o Muy bueno según el rango.

4. Opción con switch

Define opcion entre 1 y 4 y procesa: saludar, fecha simulada, despedida o finalizar.

5. Tabla de multiplicar

Define un entero e imprime su tabla del 1 al 10 con for.

6. Cuenta regresiva con while

Parte desde un contador predefinido y llega a 0 usando while.

7. Acumulador con do-while

Define un límite n y suma de 1 hasta n con do while.

8. Cajero simplificado

Con saldo, operación y monto definidos en código, simula depósito o retiro con validaciones y muestra el saldo final.

9. Comparación Python → Java

Reimplementa en Java un ejercicio que ya hayas resuelto en Python y documenta al menos cinco diferencias.

10. Preparación conceptual para POO

Analiza el cajero e identifica posibles objetos, estados y comportamientos, sin crear todavía clases propias.

1. Promedio de evaluaciones

Calcula el promedio de tres notas y determina si aprueba desde 4.0.

public class Main {
    public static void main(String[] args) {
        double nota1 = 5.2;
        double nota2 = 3.8;
        double nota3 = 4.7;
        // Calcula el promedio y muestra si aprueba.
    }
}

2. Control de stock de una cafetería

Parte con 20 sándwiches; durante 5 recreos se venden 3. Usa for, muestra el stock y avisa si quedan 5 o menos.

3. Meta de ahorro

Parte con $20.000, meta $80.000 y ahorro semanal $12.000. Usa while para calcular cuántas semanas se requieren.

4. Carga segura de una batería

Parte en 35% y 32 °C. En cada ciclo aumenta batería +15 y temperatura +2. Usa do while mientras batería < 80% y temperatura ≤ 40 °C, e informa por qué terminó.

Laboratorio · 15–20 min

Cuenta simple · de lógica a objeto

Problema: representa una cuenta con titular, saldo, depósito y retiro.

  1. Resuelve primero una versión mínima dentro de main con valores definidos directamente en código.
  2. Extrae como mínimo métodos static double depositar(double saldo, double monto) y static double retirar(double saldo, double monto).
  3. Luego crea una clase Cuenta con titular y saldo, y comportamientos depositar, retirar y mostrarSaldo.

Restricciones: atributos privados; no exponer un setSaldo() libre; el retiro no puede dejar saldo negativo; sin Scanner; debe existir un caso válido y uno rechazado.

Cierre: explica qué resolvió extraer métodos, qué cambió al crear la clase, por qué saldo debe ser privado y qué regla protege retirar().

Laboratorio · 20–25 min

PetCare · de variables a objeto

Parte con nombre, edad, peso y vacunado definidos en código. Muestra la ficha, clasifica la edad, valida peso positivo y proyecta la edad durante 3 años con un ciclo.

String nombre = "Luna";
int edad = 3;
double peso = 4.8;
boolean vacunado = false;
  1. Extrae al menos dos comportamientos a métodos, por ejemplo mostrar ficha y validar peso.
  2. Crea una clase Mascota y al menos dos instancias.
  3. Encapsula los atributos; evita que un peso ≤ 0 pueda quedar almacenado.
  4. Agrega un comportamiento para actualizar el peso correctamente y mostrarFicha() como comportamiento del objeto.

No agregar todavía: herencia, Perro/Gato, listas ni excepciones.

Checkpoint: dos mascotas funcionando, una actualización válida, un intento inválido rechazado y capacidad de explicar qué mejoró al pasar de variables sueltas a un objeto.
