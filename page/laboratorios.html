Laboratorios

Un laboratorio integra varios conceptos en una actividad guiada. Tiene contexto, etapas, restricciones, resultado esperado y evidencia. No es un ejercicio corto ni un proyecto longitudinal.

Problema: representar una cuenta con titular, saldo, depósito y retiro.

1 · Versión estructurada

Resuelve una versión mínima dentro de main usando valores definidos directamente en código. Valida que un retiro no pueda dejar saldo negativo.

String titular = "Ana";
double saldo = 50000;
double deposito = 10000;
double retiro = 25000;

2 · Extraer métodos

Crea como mínimo:

static double depositar(double saldo, double monto)
static double retirar(double saldo, double monto)

Piensa qué debería ocurrir si el monto es cero, negativo o superior al saldo disponible.

3 · Transformar en objeto

Crea una clase Cuenta con titular y saldo, y comportamientos depositar, retirar y mostrarSaldo.

Restricciones
  • Atributos privados.
  • No exponer un setSaldo() libre.
  • El saldo debe modificarse mediante comportamientos válidos.
  • Debe existir al menos un caso válido y uno rechazado.

Evidencia

  • Código ejecutable y salida de consola.
  • Respuestas breves a las preguntas de cierre.
  • Explicar oralmente dónde está el encapsulamiento.
