Semana 2

Checkpoint · de variables a objeto

Parte con los datos de una mascota definidos en código:

String nombre = "Luna";
int edad = 3;
double peso = 4.8;
boolean vacunado = false;

Primero

  • Muestra la ficha de la mascota.
  • Clasifica su edad con una decisión explicable.
  • Valida que el peso sea mayor que cero.
  • Usa un ciclo para proyectar la edad durante los próximos 3 años.

Luego

  • Extrae al menos dos comportamientos a métodos.
  • Crea una clase Mascota.
  • Crea al menos dos objetos.
  • Protege el peso para impedir estados inválidos.
  • Agrega un comportamiento para actualizar el peso y otro para mostrar la ficha.
Checkpoint esperado: dos mascotas funcionando, un cambio de peso válido, un intento inválido rechazado y capacidad de explicar qué mejoró al pasar de variables sueltas a un objeto. Todavía no agregar herencia, listas, excepciones, JavaFX ni persistencia.

Ruta del semestre

Java básico → objetos → herencia/polimorfismo → colecciones/excepciones → core reutilizable + CLI → JavaFX → MVC → persistencia JSON → JDBC → aplicación integrada.
