# Portal web del curso

La web del curso es el punto de entrada para estudiantes y la **fuente canónica de los enunciados de actividades prácticas**.

## Categorías

1. Práctica de clase — ejercicios cortos y focalizados.
2. Laboratorios — actividades guiadas e integradoras.
3. Proyecto formativo — PetCare, longitudinal durante el semestre.
4. Desafío semanal — problemas menos guiados con materia ya enseñada.
5. Grandes desafíos — 150 Java pre-POO, 100 POO, 25 JavaFX y 25 Base de datos.

Los Markdown del repositorio deben actuar como índices, referencias históricas o material complementario y enlazar a la web cuando el enunciado canónico esté publicado allí.
