Transversal

DevLog

El DevLog real vive en docs/devlog/ dentro de tu repo. Es una bitácora técnica breve, no una hoja de horas.

# DevLog · Semana XX

## Objetivo
...
## Avance
...
## Bloqueo
...
## Aprendizaje
...
## Siguiente
...

No escribas “trabajé dos horas”. Escribe qué resultado obtuviste, qué falló, qué comprendiste y qué harás después.

Reglas clave

  • Package raíz: cl.duoc.<usuario-duoc-sin-puntos>.
  • practica/ es un solo proyecto organizado por conceptos.
  • Los labs y PetCare evolucionan sin crear copias -v2 o -final.
  • README en raíz, docs/, docs/devlog/ y carpetas principales.
  • No versionar IDE, builds, logs, secretos o credenciales.
  • Al cerrar: git status → git add . → git commit → git push.
