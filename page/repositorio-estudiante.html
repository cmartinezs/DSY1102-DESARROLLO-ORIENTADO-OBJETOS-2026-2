No basta con escribir # Laboratorio y “aquí está mi trabajo”. La documentación debe permitir que otra persona entienda qué hiciste y cómo revisarlo.

El mínimo es solo el piso. Cuando aporte valor, puedes incluir:

  • tabla de contenidos;
  • requisitos;
  • instrucciones paso a paso;
  • ejemplos de uso;
  • capturas de pantalla;
  • diagramas simples;
  • decisiones de diseño;
  • problemas encontrados y cómo los resolviste;
  • estado del proyecto;
  • enlaces internos;
  • tablas y bloques de código correctamente formateados.
No se premia escribir más. Se valora que la documentación sea clara, útil, mantenida y coherente con el código real.

DOCUMENTACIÓN DESTACADA

Los mejores README podrán ser reconocidos

Los repositorios con documentación especialmente clara, útil, bien estructurada y mantenida durante el semestre podrán recibir una compensación o bonificación definida por el docente.

No es una bonificación automática por cumplir el mínimo. Se considerará claridad, utilidad, Markdown correcto, coherencia con el código y capacidad de explicar decisiones propias.
