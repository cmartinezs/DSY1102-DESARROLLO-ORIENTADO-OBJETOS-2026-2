## Criterio pedagógico

No se enseñará encapsulamiento como “poner todo `private` y generar getters/setters”. El objetivo es que el estudiante comprenda **qué estado protege**, **por qué lo protege** y **qué operaciones son válidas sobre ese estado**.

## Evidencia mínima

Al cierre de la semana el estudiante debería poder:

1. escribir Java básico con tipos, operadores, decisiones y ciclos;
2. explicar cuándo conviene extraer código a un método;
3. crear métodos con parámetros y retorno;
4. identificar una entidad, sus atributos y comportamientos;
5. crear una clase e instanciar objetos;
6. explicar el propósito del encapsulamiento más allá de getters/setters.
