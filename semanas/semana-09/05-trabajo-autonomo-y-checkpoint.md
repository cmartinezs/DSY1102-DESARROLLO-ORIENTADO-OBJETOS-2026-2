# 05 · Trabajo autónomo, evidencias y cierre

## Antes del sábado
1. Revisar el recurso institucional **2.1.1 Control de Versiones** de manera autónoma.
2. Estudiar PPT de Maven, configuración JavaFX, escenas, Scene Builder y vinculación FXML-Controller.
3. Comprobar `java -version`, `mvn -version` y la ejecución del proyecto base.
4. Tomar nota del primer bloqueo y de cómo intentaste resolverlo.

## Después del taller
1. Completar el [laboratorio](../../labs/semana-09/) y dos [ejercicios breves](../../ejercicios/semana-09/).
2. Agregar una mejora pequeña sin copiar una solución distinta: otro control o una validación.
3. Subir commits incrementales en tu repositorio DSY1102-012V-nombre-apellido.
4. Crear `docs/devlog/semana-09.md` con objetivo, avance, bloqueo, aprendizaje y próximo paso.

## Comprobación observable
- [ ] `mvn javafx:run` abre la ventana.
- [ ] Explicas `Stage`, `Scene` y `start`.
- [ ] FXML se carga, el Controller recibe el evento.
- [ ] El evento usa un objeto Java real.
- [ ] La entrada vacía no produce error sin control.
- [ ] Existe una evidencia de ejecución y un commit coherente.

**No exigimos:** `TableView`, JSON, JDBC ni patrones de arquitectura todavía.
