# Java vs Python: qué cambia y qué permanece

El paso desde Python hacia Java puede sentirse grande porque Java exige declarar más estructura de forma explícita. Sin embargo, muchos fundamentos permanecen.

## Lo que permanece

Siguen existiendo:

- variables;
- condiciones;
- ciclos;
- funciones/métodos;
- operadores;
- algoritmos;
- descomposición de problemas.

## Lo que se vuelve más explícito

Java exige declarar con mayor claridad aspectos como:

- tipos;
- clases;
- métodos;
- visibilidad;
- punto de entrada;
- estructura del proyecto.

Ejemplo conceptual:

Python:

```python
edad = 4
```

Java:

```java
int edad = 4;
```

La idea de variable no cambió. Cambió la sintaxis y el nivel de explicitud.

## Un error común

Pensar:

> “Como Java es orientado a objetos, cualquier código Java ya es POO.”

Eso es incorrecto.

Podemos escribir Java de forma muy procedural, dejando casi toda la lógica dentro de `main`.

La POO aparece cuando comenzamos a diseñar alrededor de:

```text
clases
objetos
estado
comportamiento
responsabilidades
colaboración
```

## Estrategia de aprendizaje

En vez de intentar memorizar Java completo de una vez:

```text
concepto conocido
→ sintaxis Java
→ práctica pequeña
→ incorporar al diseño orientado a objetos
```

Así evitamos aprender dos dificultades al mismo tiempo sin distinguirlas: la sintaxis del lenguaje y el paradigma.
