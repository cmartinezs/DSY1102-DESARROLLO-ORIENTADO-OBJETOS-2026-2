## Idea central

El cambio importante de esta asignatura no es pasar de Python a Java. El cambio importante es comenzar a resolver problemas preguntando:

```text
¿Qué conceptos existen en el problema?
¿Qué sabe cada uno?
¿Qué puede hacer cada uno?
¿Cómo colaboran?
```

Ese razonamiento será la base para clases, objetos, encapsulamiento, relaciones y los demás conceptos que aparecerán durante el semestre.
