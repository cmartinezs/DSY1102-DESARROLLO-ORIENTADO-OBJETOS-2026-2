## Regla de organización

La ubicación canónica de los ejemplos reutilizables es:

```text
examples/
├── semana-01/
├── semana-02/
└── ...
```

Las carpetas dentro de `semanas/semana-XX/` pueden enlazar a estos ejemplos, pero no deben mantener una segunda copia activa del mismo código.
