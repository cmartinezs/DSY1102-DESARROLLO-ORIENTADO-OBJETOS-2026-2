# Ejemplos · Semana 02

Ejemplos disponibles para acompañar **Métodos, clases y encapsulamiento**.

La Semana 02 está liberada completa por criterio curricular, aunque alguno de estos conceptos todavía no se haya alcanzado en la sesión presencial.

## Orden sugerido

1. [`PetCareBasico.java`](PetCareBasico.java) — fundamentos + primer método `static` con parámetros.
2. [`ProductoDemo.java`](ProductoDemo.java) — clase, objeto, constructor y encapsulamiento básico.

## Alcance

Estos ejemplos cubren progresivamente:

- métodos `static`;
- parámetros;
- retorno cuando corresponda;
- agrupación de datos relacionados;
- creación de clases y objetos;
- constructor;
- atributos `private`;
- comportamiento que protege el estado interno.

Todavía no corresponde introducir herencia, colecciones, excepciones, JavaFX ni persistencia.

> Esta carpeta `examples/semana-02/` es la ubicación canónica de los ejemplos reutilizables de la semana. Las referencias dentro de `semanas/semana-02/` deben apuntar aquí.
