# Ejercicios breves · Semana 09

**Prerrequisito:** poder ejecutar el [proyecto demo](../../ejemplos/semana-09/). Cada ejercicio tiene una sola meta y se resuelve en 5–20 minutos, modificando una copia propia del demo o un ejemplo mínimo independiente.

1. **Título y escena (5 min).** Cambia el título de `Stage` y el tamaño de `Scene`. Evidencia: captura de la ventana y explicación de ambas clases.
2. **Segundo TextField (10 min).** Agrega edad de mascota en FXML; lee ambos campos desde Controller. Valida que sea un entero positivo. Evidencia: una ejecución correcta y otra inválida.
3. **Evento de limpiar (10 min).** Agrega un Button con `onAction` que limpie controles y feedback. Evidencia: estado antes y después del clic.
4. **Constructor (15 min).** Reutiliza una clase Java con constructor válido y presenta dos atributos mediante el Controller. Evidencia: no hay import de JavaFX en el modelo.
5. **Depuración FXML (10 min).** Cambia intencionalmente un `fx:id` o la ruta FXML, anota el síntoma y corrige el fallo. Evidencia: causa raíz y corrección.
6. **Desafío autónomo (15–20 min).** Añade un `ComboBox` con una opción de categoría; al presionar Guardar, compón un resumen con el objeto registrado. No usar JSON ni BD.

## Entrega y reflexión
Subir commits del trabajo, captura de ejecución y DevLog. No se exige terminar todos en clase; el docente prioriza los esenciales y los demás son práctica autónoma.

**No confundir:** los ejercicios son focalizados; el [lab](../../labs/semana-09/) es una actividad guiada e integradora distinta.
