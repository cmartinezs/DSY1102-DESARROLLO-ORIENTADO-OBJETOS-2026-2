# Ejercicios · Semana 06

## Práctica base

### 1. Array de animales
Crea un `Animal[]`, almacena distintos subtipos y recórrelo mostrando el comportamiento de cada objeto.

### 2. Migración a colección
Reemplaza el array por `List<Animal>` y permite agregar nuevos animales sin definir un tamaño máximo inicial.

### 3. Buscar por identificador
Implementa una operación que reciba un identificador y encuentre el animal correspondiente.

### 4. Eliminar un animal
Permite eliminar un objeto de la colección y comprobar el resultado.

### 5. Caso inválido
Decide qué debe ocurrir cuando se busca o elimina un animal inexistente. Implementa una primera solución controlada mediante excepciones.

## Regla de trabajo
Antes de programar cada ejercicio escribe brevemente:
- qué debe resolver;
- qué datos necesita;
- qué objeto debería asumir la responsabilidad;
- qué podría salir mal.
