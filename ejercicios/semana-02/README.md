# Ejercicios · Semana 02

1. **Descuento por monto:** determinar descuento según total de compra.
2. **Clasificación de edad:** usar `if/else if/else` para clasificar una edad.
3. **Tabla de multiplicar:** mostrar del 1 al 10 usando `for`.
4. **Cuenta regresiva:** resolver con `while`.
5. **Acumulador:** sumar números del 1 al 100.
6. **Método `esPar(int numero)`:** retornar `boolean`.
7. **Método `calcularTotal(double precio, int cantidad)`:** retornar el total.
8. **Método `puedeComprar(double saldo, double precio)`:** retornar si existe saldo suficiente.

Objetivo: consolidar control de flujo y comenzar a sacar lógica desde `main` mediante métodos pequeños.
