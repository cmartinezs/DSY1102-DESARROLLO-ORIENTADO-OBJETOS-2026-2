## Regla

Cada semana disponible contiene ejercicios pequeños y progresivos. Deben resolverse con lo efectivamente visto en clases; no se exige contenido futuro para completar una práctica anterior.

Esta vertical también es el hogar de práctica breve, refuerzo y desafíos que no califican como laboratorio formal. La ausencia de una semana en este índice no implica que el contenido curricular de esa semana no exista; indica únicamente que no hay un set de ejercicios independiente publicado aquí.
