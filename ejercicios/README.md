# Ejercicios mínimos de aplicación significativa · DSY1102

**Qué es un ejercicio:** el problema más pequeño que requiere aplicar **una habilidad focal**, tomar una decisión y comprobar un resultado; no una demostración sintáctica ni un laboratorio reducido.

El banco se rige por el [estándar DSY1102 de ejercicios mínimos](../docs/ESTANDAR-EJERCICIOS-MINIMOS-DSY1102.md), compatible con el [estándar pedagógico incremental](../docs/ESTANDAR-DISENO-PEDAGOGICO-INCREMENTAL.md).

## Cómo se usa

1. Entra a la semana que corresponda. Cada ejercicio especifica **foco**, **problema**, **dato de prueba/resultado esperado**, **caso límite** cuando aplica y **pregunta de comprensión**.
2. Resuelve con lo enseñado hasta esa semana. Cuando hay una herramienta nueva (JavaFX/Maven/JSON), se declara el punto de partida y se proporcionan pistas útiles.
3. Ejecuta el caso principal y prueba el límite o rechazo. Verifica que el resultado coincida; una captura o salida de consola puede bastar como evidencia.
4. El ejercicio no necesita un repo nuevo, un diagrama ni arquitectura extra. Sigue el DevLog semanal solo según la política global del curso.

## Qué NO está incluido en el banco mínimo

- **Ejemplos**: programas para observar la API/sintaxis; viven en `ejemplos/`.
- **Laboratorios**: soluciones integradoras independientes; viven en `labs/`.
- **PetCare**: desarrollo longitudinal del semestre.
- **Desafíos**: problemas más abiertos para transferir conocimientos.
- **Talleres guiados históricos**: [evolución de Cuenta y Scanner (semana 04)](semana-04/), [MarketApp (taller complementario de semana 06)](../labs/semana-06/taller-opcional-marketapp/). Son oportunidades de refuerzo **opcionales**, no ejercicios mínimos obligatorios.
