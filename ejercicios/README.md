## Regla

Cada semana contiene ejercicios pequeños y progresivos. Deben resolverse con lo efectivamente visto en clases; no se exige contenido futuro para completar una práctica anterior.

Un ejercicio debe tener un foco acotado y normalmente resolverse en pocos minutos. Si requiere múltiples responsabilidades, documentación extensa, evidencias y una secuencia de implementación, corresponde a `labs/`, no a esta carpeta.
