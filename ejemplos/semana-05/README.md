# Ejemplos · Semana 05

1. [HerenciaBasica.java](HerenciaBasica.java): `extends` y `super`, salida `Destino: Biblioteca`.
2. [Sobrescritura.java](Sobrescritura.java): `@Override`, salidas `Normal: 5000` y `Estudiante: 4000`.
3. [DespachoDinamico.java](DespachoDinamico.java): polimorfismo, salidas `Aviso general` y `Alerta crítica`.

## Ejecutar
Crear un proyecto Java 21 independiente, copiar estos tres archivos a `src`, ejecutar cada clase desde su `main` y contrastar las salidas. No requieren PetCare ni el laboratorio semanal.

**Observar:** diferencia entre heredar, sobrescribir y ejecutar un método polimórfico. [Ejercicios de aplicación](../../ejercicios/semana-05/).
