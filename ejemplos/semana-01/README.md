# Ejemplos · Semana 01

Ejemplos simples para acompañar **Paradigma OO: fundamentos del lenguaje**.

El objetivo no es introducir todavía el desarrollo formal de clases de dominio, sino familiarizarse con la estructura básica de Java, tipos, operadores y estructuras de control.

> **Regla de esta etapa:** durante la Semana 01 no se utiliza entrada por teclado (`Scanner`, `System.in`, etc.). Todos los datos de cada ejemplo quedan preconfigurados directamente en el código. La entrada interactiva se incorporará más adelante, una vez trabajado el concepto de clases.

Cada archivo puede ejecutarse de forma independiente y utiliza valores declarados directamente en el método `main`. En IntelliJ usa JDK 21, copia los seis archivos a `src` y ejecuta su `main`. Resultados verificables: `Ejemplo04CicloFor` termina en **15**; `Ejemplo05WhileDoWhile` imprime 1, 2, 3 en ambos ciclos; el ejemplo integrador calcula un promedio y una tabla de multiplicar.
