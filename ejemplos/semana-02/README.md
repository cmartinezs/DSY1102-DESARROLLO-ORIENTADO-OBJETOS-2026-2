# Ejemplos · Semana 02

Ejemplos reutilizables para acompañar **métodos, clases, objetos y encapsulamiento**.

Esta carpeta pertenece al contenido curricular de la semana y utiliza contextos pequeños e independientes.

## Orden sugerido

1. [`01-MetodoSimple.java`](01-MetodoSimple.java) — primer método `void` sin parámetros.
2. [`02-MetodosParametrosRetorno.java`](02-MetodosParametrosRetorno.java) — parámetros, argumentos y retorno.
3. [`03-ProductoBasico.java`](03-ProductoBasico.java) — primera clase y dos objetos.
4. [`ProductoDemo.java`](ProductoDemo.java) — constructor, `private` y comportamiento que protege stock.

## Estrategia

```text
ejemplo mínimo
    ↓
explicación del concepto
    ↓
mini modificación
    ↓
otro ejemplo
```

El objetivo es comprender herramientas generales de Java y POO sin depender de un proyecto longitudinal.

## Alcance

Todavía no corresponde introducir:

- `Scanner` como eje de los ejemplos;
- arrays o colecciones;
- herencia;
- interfaces;
- excepciones;
- JavaFX;
- persistencia.

> El proyecto transversal tiene su propia ubicación y no forma parte de esta carpeta de ejemplos semanales.
