## Regla canónica

Cada ejemplo debe demostrar una idea claramente identificable y poder ejecutarse sin depender del proyecto formativo ni de otro ejemplo, salvo que la dependencia sea parte explícita del objetivo pedagógico.

Las carpetas dentro de `semanas/semana-XX/` pueden enlazar estos ejemplos, pero no deben mantener una segunda copia activa del mismo código.
