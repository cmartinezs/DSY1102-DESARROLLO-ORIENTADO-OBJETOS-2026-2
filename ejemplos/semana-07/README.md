# Ejemplos · Semana 07 · Abstractas, interfaces y polimorfismo

## Demostraciones mínimas (vigentes)
1. [ClaseAbstracta.java](ClaseAbstracta.java) — clase abstracta, método abstracto y subtipo concreto. Salida: `Área: 16`.
2. [InterfazCapacidad.java](InterfazCapacidad.java) — una interfaz expresa una capacidad que no todos los objetos necesitan. Salidas: `Lámpara encendida`, `Vela encendida con fósforo`.
3. [PolimorfismoInterfaz.java](PolimorfismoInterfaz.java) — un parámetro de interfaz admite dos implementaciones. Salidas: `Correo enviado` y `Aviso mostrado`.

Para ejecutar: en IntelliJ IDEA, crea un proyecto **Java 21**, copia los archivos a `src` y ejecuta cada `main`. Son autónomos, con clases auxiliares anidadas.

## Solución de integración (referencia, no ejemplo atómico)
[MediaHub, proyecto EA1 completo](proyecto-integracion-ea1/) conserva su código original y valor demostrativo: modelo, servicio, entrada, menús, herencia, interfaces y colecciones. Es una **demostración de integración** de múltiples conceptos; no es un ejemplo mínimo, ni un laboratorio obligatorio, ni una solución de la evaluación. Para estudiarlo, abre y ejecuta su proyecto por separado según las instrucciones de la carpeta.

Los [ejercicios focales](../../ejercicios/semana-07/) permiten aplicar los aprendizajes en otros casos; el [laboratorio](../../labs/semana-07/) integra con mayor guía.
