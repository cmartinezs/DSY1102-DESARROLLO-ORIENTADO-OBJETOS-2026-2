# Documentación transversal

Este directorio reúne contenidos reutilizables a lo largo del semestre que no pertenecen exclusivamente a una semana.

Aquí podrán incorporarse progresivamente guías sobre Java, IntelliJ IDEA, Maven, JavaFX, Git/GitHub, JDBC, convenciones de código, depuración y otras prácticas relevantes para la asignatura.
