# Documentación transversal

Este directorio reúne contenidos reutilizables a lo largo del semestre que no pertenecen exclusivamente a una semana.

## Material complementario

El índice principal está en [`docs/extras/README.md`](./extras/README.md). Allí encontrarás un **roadmap sugerido** para revisar los recursos según el momento del curso.

Los extras actuales cubren:

- uso del computador y organización de proyectos;
- herramientas mínimas para desarrollar en Java;
- terminal;
- Markdown;
- Git y GitHub;
- estrategia de ramas GitFlow en versión introductoria;
- conceptos fundamentales de programación;
- lógica proposicional;
- matemáticas aplicadas a ejercicios de programación;
- Java y programación orientada a objetos;
- estrategias para resolver problemas antes de escribir código.

> [!IMPORTANT]
> El material está adaptado específicamente para **DSY1102**, donde Java se aprende por primera vez. Los contenidos complementarios no asumen Spring Boot, APIs REST, bases de datos, Docker ni arquitectura backend.

También se mantiene un [`backlog de sugerencias`](./extras/SUGERENCIAS-COMPLEMENTARIAS.md) con futuros temas de apoyo que pueden incorporarse a medida que aparezcan necesidades reales en las secciones.
