# 🧭 Material complementario — DSY1102 Desarrollo Orientado a Objetos

Este directorio reúne material de apoyo para **DSY1102**, adaptado desde recursos originalmente preparados para una asignatura Fullstack Backend.

> [!IMPORTANT]
> Aquí se comienza con los fundamentos de Java. Los materiales iniciales utilizan ejemplos pequeños; a medida que avanza el curso también encontrarás guías de apoyo para JavaFX, Maven, JSON y persistencia. No necesitas conocer Spring Boot, Docker ni servicios externos para estudiar estas guías.

## Puentes de la Unidad 2: de colecciones a JavaFX y JSON

Si el curso empieza a hablar de `JSON`, `Jackson`, `DAO`, `FXML`, `ObservableList` o `Maven` antes de que se entienda el vocabulario subyacente, tenemos una ruta de apoyo **voluntaria, breve y contextual**:

**[Abrir la biblioteca de 11 microcápsulas de la Unidad 2](./puentes-unidad-02/)**.

Parte por dato, registro y colección; explica JSON sin exigir JavaScript; continúa por conversión de objetos Java, errores, manejo de archivos, Maven, interfaz y pruebas. Incluye enlaces a las dos guías existentes de Streams y NIO.2, sin duplicarlas.

**Actividad práctica:** [Detective JSON](https://academic-labs.adumun.cl/activities/detective-json/), actividad interactiva con seis desafíos y exportación TXT. Puedes resolverla en el navegador y entregar el archivo solo si tu docente lo solicita.

`gitflow`. Se revisa después de dominar commit, push, pull y ramas. No es requisito aprender flujos de release, despliegue o automatización.

## Criterio de adaptación

Al migrar el material se aplicaron estas reglas:

1. **Java puro antes que frameworks.**
2. **Primero el concepto, después la sintaxis.**
3. **No anticipar Spring Boot, REST, JPA, bases de datos, Docker ni despliegues.**
4. **No usar Streams, concurrencia, patrones GoF o arquitectura como conocimientos de entrada.**
5. Los ejemplos se expresan como programas pequeños, clases y objetos del dominio cotidiano.
6. Git/GitHub se enseña como herramienta de trabajo y respaldo; las prácticas profesionales avanzadas se dejan como referencia posterior.
7. Cuando un concepto avanzado ayuda a explicar algo básico, se menciona sólo como horizonte, sin exigir su implementación.
