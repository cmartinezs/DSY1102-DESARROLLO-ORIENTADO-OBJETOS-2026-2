# Semana 06 · Laboratorio autónomo: Inscripciones a talleres

**DSY1102 · Arrays, List/ArrayList y manejo de excepciones · Java 21**

## ¿Qué construiremos?
Un registro sencillo para un centro cultural que inscribe personas en talleres. Partiremos de `Inscripcion[]` para descubrir limitaciones y evolucionaremos **dentro del mismo laboratorio** a `ArrayList<Inscripcion>`. Luego agregaremos búsqueda, eliminación y tratamiento de datos incorrectos.

Este proyecto **se crea desde cero** como `RegistroTalleres`. No requiere Veterinaria I ni ningún laboratorio anterior. No sustituye el proyecto formativo PetCare.

## Resultado verificable
- [ ] Inicia IntelliJ y ejecuta un `Main` nuevo.
- [ ] Explica qué ocurre si un array tiene longitud fija.
- [ ] Agrega, recorre, busca y elimina inscripciones usando una `List`.
- [ ] Rechaza duplicados sin cerrar el programa.
