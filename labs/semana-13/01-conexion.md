# Incremento 1 · Conexión
Instala JDK 21, Maven, IntelliJ IDEA y MariaDB Server. Verifica java -version y mvn -version. En Windows comprueba el servicio MariaDB en services.msc. Abre el cliente SQL como administrador local, ejecuta esquema.sql y crea un usuario de práctica con permisos SELECT, INSERT, UPDATE y DELETE solo sobre la base del lab. No compartas contraseñas. En IntelliJ abre codigo/pom.xml como proyecto Maven y recarga dependencias. Configura DB_USER y DB_PASSWORD en Run > Edit Configurations > Environment variables; para terminal PowerShell usa $env:DB_USER y $env:DB_PASSWORD con tus valores locales. [Configuración detallada R07](../../clases/unidad-02/capsula-tiempo-fx/jdbc/01-r07-conexion-insert-validacion.md).
Ejecuta [esquema SQL](codigo/esquema.sql) una vez; SELECT * FROM capsula debe mostrar dos filas en una base nueva. Crea [pom.xml](codigo/pom.xml) y [DatabaseConnection](codigo/src/main/java/database/DatabaseConnection.java). JDBC es la API, Connector/J el driver y MariaDB el servidor. URL jdbc:mariadb://localhost:3306/capsula_db. Crea [TestConnection](codigo/src/main/java/app/TestConnection.java), ejecuta su main o desde codigo: mvn compile exec:java -Dexec.mainClass=app.TestConnection. Checkpoint: Conexión exitosa. Si falla: No suitable driver = dependencia; connection refused = servicio/puerto; access denied = credenciales/permisos; unknown database = esquema.
