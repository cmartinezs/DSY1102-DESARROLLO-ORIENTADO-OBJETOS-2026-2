# Incremento 3 · Escritura y verificación
Completa [CapsulaDao](codigo/src/main/java/dao/CapsulaDao.java) con insertar, actualizar y eliminar. Los ? se enlazan desde 1 y sin comillas; Date.valueOf convierte LocalDate. executeUpdate devuelve filas afectadas. UPDATE y DELETE deben filtrar por id. No concatenar valores SQL ni esconder SQLException.
Ejecuta [TestDao](codigo/src/main/java/app/TestDao.java) desde IntelliJ o mvn compile exec:java -Dexec.mainClass=app.TestDao. Crea un registro de prueba con título único, recupera ID, edita mensaje, verifica lectura y elimina solo esa fila. Checkpoint: CRUD OK. Prueba además un título con apóstrofo, un ID inexistente y desconexión controlada. Verifica con SELECT * FROM capsula. Guarda evidencia de cada operación; no borres datos ajenos.
