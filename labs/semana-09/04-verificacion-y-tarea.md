# 04 · Verificación y desafío para la casa

## En clase
- [ ] `mvn javafx:run` funciona.
- [ ] FXML y Controller están vinculados.
- [ ] El clic usa datos del formulario.
- [ ] El modelo Java no importa JavaFX.
- [ ] Se demuestra un caso correcto y uno inválido.

## Trabajo autónomo posterior
1. Añade una segunda entrada (p. ej., especie o edad) con validación correspondiente.
2. Implementa otro evento (p. ej., limpiar el formulario).
3. Realiza al menos dos [ejercicios de refuerzo](../../ejercicios/semana-09/).
4. Sube commits y completa `docs/devlog/semana-09.md`: avance, bloqueo, aprendizaje y siguiente paso.

## Evidencia
Capturas o breve descripción de pruebas, commits y respuesta a «¿qué parte seguiría funcionando si quitáramos JavaFX?».

**Checkpoint:** aplicación funcional con mejora propia y pasos reproducibles.
