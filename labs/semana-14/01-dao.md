# Incremento 1 · DAO
Instala JDK 21, Maven, IntelliJ IDEA y MariaDB Server. Verifica java -version y mvn -version. En Windows comprueba el servicio MariaDB en services.msc. Abre el cliente SQL como administrador local, ejecuta esquema.sql y crea un usuario de práctica con permisos SELECT, INSERT, UPDATE y DELETE solo sobre la base capsula_fx_db. No compartas contraseñas. En IntelliJ abre codigo/pom.xml como proyecto Maven y recarga dependencias. Configura DB_USER y DB_PASSWORD en Run > Edit Configurations > Environment variables; para terminal PowerShell usa $env:DB_USER y $env:DB_PASSWORD con tus valores locales. [Configuración detallada R07](../../clases/unidad-02/capsula-tiempo-fx/jdbc/01-r07-conexion-insert-validacion.md).
Abre [pom.xml](codigo/pom.xml), ejecuta [esquema](codigo/esquema.sql), crea [modelo](codigo/src/main/java/model/Capsula.java), [conexión](codigo/src/main/java/database/DatabaseConnection.java). Define [interfaz CapsulaDao](codigo/src/main/java/dao/CapsulaDao.java) y [implementación](codigo/src/main/java/dao/CapsulaDaoMySql.java). Contrato declara operaciones; implementación contiene SQL. Compila con mvn compile. Crea un main temporal con CapsulaDao dao = new CapsulaDaoMySql(); imprime dao.listarTodos().size(). Checkpoint: 2 en una base nueva. No uses SQL en el controlador. En esta guía se usa Maven no modular; si tu proyecto tiene module-info, requiere javafx.controls, javafx.fxml, java.sql, y abre controller a javafx.fxml y model a javafx.base; revisa además el módulo del driver. [Interfaces y módulos](../../semanas/semana-13/referencias.md).
