# Práctica integradora liberada · Diseño original EP1

Este directorio publica el material que originalmente se preparó como **Evaluación Parcial 1** de DSY1102. Ya no se considera una evaluación vigente y queda disponible como **práctica integradora** para repasar y conectar los contenidos de la Experiencia de Aprendizaje 1.

## Versiones disponibles

- [Versión A · EventPass](version-a-eventpass.md)
- [Versión B · RepairDesk](version-b-repairdesk.md)
- [Versión C · CargoTrack](version-c-cargotrack.md)

Las tres versiones trabajan la misma progresión pedagógica mediante dominios distintos: análisis inicial, Java elemental, responsabilidades y SRP, herencia/abstracción/interfaces/polimorfismo, colecciones (`List`, `Set`, `Map`) y manejo de excepciones.

## Cómo usar este material

Puedes escoger cualquiera de las tres versiones y desarrollarla de principio a fin. Si quieres simular la experiencia original, resuelve una parte antes de leer la siguiente.

> Las instrucciones de AVA y entrega por commit se mantienen porque formaban parte del diseño original. Para esta publicación liberada no constituyen una entrega vigente.
