# 04 · Buscar y eliminar

Define un criterio de búsqueda comprensible para el dominio.

Puede ser nombre, identificador u otro dato ya existente.

Evita devolver mensajes impresos desde el servicio. Una operación debería devolver un resultado o señalar que no pudo cumplir su objetivo.

## Trabajo

- implementar búsqueda;
- probar un caso existente;
- implementar eliminación o retiro;
- comprobar qué ocurre con un elemento inexistente.

## Checkpoint

- [ ] la búsqueda tiene un criterio explícito;
- [ ] la eliminación modifica la colección correctamente;
- [ ] la lógica no depende de `Scanner`;
- [ ] ya existe una situación inválida útil para introducir excepciones.
