# 02 · Probar un array y observar sus limitaciones

Antes de saltar a `ArrayList`, usa un array para hacer visible el problema.

```java
Mascota[] mascotas = new Mascota[3];
```

Prueba:

- agregar objetos;
- recorrerlos;
- consultar una posición;
- simular qué ocurre cuando necesitas una cuarta mascota;
- pensar cómo eliminarías un elemento.

## Checkpoint

- [ ] puedo recorrer un array de objetos;
- [ ] comprendo su tamaño fijo;
- [ ] puedo explicar por qué gestionar altas y bajas se vuelve incómodo;
- [ ] tengo una razón concreta para migrar a una colección dinámica.
