# 04 · Integrar el flujo completo

Prueba PetCare de principio a fin.

El flujo mínimo debería demostrar:

1. crear un subtipo válido;
2. registrarlo;
3. listar;
4. buscar;
5. ejecutar comportamiento polimórfico;
6. utilizar una capacidad por interfaz si existe;
7. provocar y manejar una situación inválida.

## Checkpoint

- [ ] todas las piezas anteriores funcionan juntas;
- [ ] no reescribí Semana 06;
- [ ] la CLI coordina interacción;
