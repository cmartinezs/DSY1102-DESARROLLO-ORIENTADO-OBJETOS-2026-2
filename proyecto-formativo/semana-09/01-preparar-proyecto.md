# 01 · Preparar el proyecto

1. Ejecuta y verifica el PetCare de semana 8 antes de modificarlo.
2. Identifica dónde viven modelo, servicio y CLI.
3. Añade una configuración Maven y dependencias JavaFX sin cambiar reglas ni colecciones.
4. Crea una clase `Application` en el paquete de UI. Conservar CLI como punto de entrada separado.
5. Muestra una ventana vacía y documenta cómo la ejecutaste.

**Checkpoint:** CLI y UI pueden arrancar, y `core` no requiere JavaFX. No generar nuevas capas vacías.
