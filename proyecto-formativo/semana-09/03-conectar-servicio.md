# 03 · Conectar con PetCareService

1. Recupera el mismo `PetCareService` que usaba tu CLI (sin clonar sus datos/reglas).
2. En el evento, lee lo que ingresó el usuario y delega en una operación del servicio.
3. Convierte el resultado o error en un mensaje de interfaz.
4. Verifica que cambiar la UI no obligaría a tocar las clases de modelo.
5. Evita duplicar listas de mascotas entre Controller y Service.

**Checkpoint:** una acción de UI utiliza efectivamente un método del core; puedes seguir ejecutando la CLI. Si tu diseño no incluye esa operación, justifica la adaptación mínima.
