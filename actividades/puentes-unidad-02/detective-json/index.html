Detective JSON

¿Un mensaje puede convertirse en texto? ¿Qué pasa con las comas, los arreglos y las claves repetidas? Investiga seis casos reales sin necesitar saber JavaScript.

Tiempo sugerido: 15–25 minutos · Sin cuenta · Sin backend · Funciona offline si descargas este HTML.

Antes de empezar

JSON es un formato de datos, no un lenguaje que debas programar. Un objeto usa { }, una lista/arreglo usa [ ] y los textos se escriben entre "comillas dobles".

  • Lee el ejemplo de cada tarjeta; puedes modificarlo sin afectar archivos de tu computadora.
  • Elige un diagnóstico y usa «Revisar mi diagnóstico» para recibir una explicación.
  • «Comprobar texto» usa JSON.parse en tu navegador: detecta errores de sintaxis y comprueba si la raíz es un arreglo. No detecta necesariamente claves duplicadas; ese caso lo analizas como detective.
  • Al finalizar exporta tu trabajo a un TXT y entrégalo mediante el AVA o medio acordado con tu docente. No se transmite ninguna respuesta a ADÜMÜN.

Importante: un JSON puede ser legible por un programa y aun así violar reglas de negocio o contener propiedades ambiguas. En Java R06, Jackson está configurado para rechazar claves duplicadas dentro de un mismo objeto.
